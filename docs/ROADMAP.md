# 千帆集文化共创园 官网与商城规划

## 一期：园区官网（已完成雏形）
吃 / 住 / 玩 / 逛 / 乐 / 购 六大板块导航，内容集中在 `lib/data.ts`。
待补：真实照片、房型与价格、营业时间、电话、地图、游玩项目票价。

## 二期：农产品商城
**目标**：线上卖园区及周边农产品，支持到园自提与快递。

| 模块 | 内容 |
|---|---|
| 商品 | 分类、SKU（规格/重量）、库存、上下架、时令标签 |
| 购物车与订单 | 下单、取消、状态流转（待付款→待发货/待自提→已完成）、售后 |
| 支付 | 微信支付（H5 / 小程序 / 公众号），支付宝可选 |
| 配送 | 快递（运费模板）+ 园区自提（核销码）|
| 后台 | 商品、订单、库存、发货、数据看板 |

## 三期：会员与套餐
- **会员等级**：普通 / 年卡 / 家庭卡，权益含住宿折扣、游玩项目次数、农产品折扣。
- **套餐商品**：田园季卡（按期配送时令蔬果）、认养一亩田、住宿+游玩组合票。
- **积分与优惠券**：消费累计，复购和裂变。
- **核销**：线下项目扫码核销（滑道、小火车、电影院等）。

## 技术方案建议
- 前端：现有 Next.js。移动端是主要流量，建议同步做微信小程序或把站点做成微信内可用的 H5。
- 后端与数据库：Next.js API + PostgreSQL（Prisma），订单、会员、库存强一致，需要事务。
- 登录：微信登录（手机号绑定）。
- 部署：国内云（阿里云/腾讯云）；官网面向国内用户，需要 ICP 备案。

## 上线前需要确认的资质与规则（请向主管部门或律师核实）
- ICP 备案；微信支付商户号（需营业执照）。
- 销售食用农产品通常需要食品经营相关许可，请按当地要求办理。
- 会员储值/预付费属于预付式消费，需遵守预付卡及消费者权益相关规定，建议以“权益套餐”而非随意充值设计，并明确退款规则。
- 用户隐私政策与个人信息保护合规。

## 建议的推进顺序
1. 补齐一期真实内容并上线，先接地图与联系方式。
2. 预订咨询表单接通知（企业微信/邮件），数据入库。
3. 做商品与订单（先自提+到园购买，降低物流复杂度）。
4. 再上会员套餐与核销。
